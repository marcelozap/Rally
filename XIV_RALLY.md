# XIV Rally

Rally is a module inside XIV OS, not a separate operating system.

## Root Law

Nothing is only itself.

## Rally Role

Rally is the movement / sport / focus module.

It connects:
- tennis
- rhythm
- body
- discipline
- recovery
- competition
- identity
- daily play

## XIV Command

Locate -> Widen -> Route -> Return

## Rally Command

Move clean.

## What Rally Should Become

Rally should not only be a tennis game. It should become the body/rhythm module of XIV OS.

When life collapses into one node, Rally gives the body a clean loop:
- tap
- swing
- breathe
- recover
- return

## Integration With XIV OS

XIV OS is the root command center.

Rally should expose:
- today's play state
- tennis/body progress
- recovery prompts
- streaks without shame
- one clean movement action
- connection back to MusicOS and Green Machine

## Rule

Do not turn Rally into another separate world.

Rally is a node in the field.
XIV holds the field.
